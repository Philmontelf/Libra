# Cancer

This folder contains a HTML claw [Code.html](Code.html) that executes actions written in the input box.

## How to use

- Download [Code.html](Code.html).

- Open it.

- Insert a number sequence in the input box.

- Click on **Execute**: The claw executes the input actions.
