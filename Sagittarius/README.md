# Sagittarius

This folder contains HTML fishes [Code.html](Code.html) that visually shows if a simple mathematical calculation is correctly solved by the user.

## How to use

- Download [Code.html](Code.html).

- Open it.

- Insert the solution in the input box.

- Click on **Verify**: The arrow will get closer to the target based on how much the input solution is close to the correct one.
